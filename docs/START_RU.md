# Rankforge: установка и первое занятие

Rankforge - локальная учебная игра про backend, базы данных, эксплуатацию и работу с данными. Ты выбираешь задание в браузере, пишешь настоящий код в VS Code и работаешь с настоящим терминалом. Интерфейс и наставник общаются на английском.

Программа рассчитана на знакомство с основами программирования. Python, VS Code и backend-инструменты можно осваивать по ходу; если термин или приём незнаком, попроси наставника объяснить его.

В первой версии доступны шесть заданий. System design, нагрузка, Kafka, расширенный Data Engineering и базовый ML уже включены в программу будущих глав, но эти главы ещё не исполняемые.

Если сначала хочешь посмотреть, как это выглядит, открой [обзор экранов со скриншотами](TOUR_RU.md).

## Что нужно установить

- [Node.js 24 LTS или новее](https://nodejs.org/en/download), вместе с npm.
- [Python 3.10 или новее](https://www.python.org/downloads/), доступный командой `python3`.
- [Git](https://git-scm.com/downloads).
- [VS Code](https://code.visualstudio.com/download) 1.110 или новее и команду `code` в PATH.
- Настольный Chromium-браузер: например, Chrome, Chromium или Brave.
- Docker Desktop/Engine с Compose понадобится только для задания с nginx. Для запуска самой игры и остальных заданий первой главы Docker не нужен.

Основной проверенный desktop-сценарий - macOS. Ядро приложения также проходит проверки в Linux arm64/amd64. Для GPT-подключения на desktop Linux нужен `secret-tool` и разблокированное хранилище Secret Service; в Debian/Ubuntu утилита обычно поставляется пакетом `libsecret-tools`. Полная интеграция с desktop Linux и native Windows пока не прошла личную приёмку.

На Mac открой Command Palette в VS Code (`Cmd+Shift+P`), выполни **Shell Command: Install 'code' command in PATH**, затем открой новый терминал.

Проверь команды:

```sh
node --version
npm --version
python3 --version
code --version
```

## Скачать и запустить

В терминале перейди в папку, где хочешь хранить проект, и выполни:

```sh
git clone https://github.com/KMNervanin/rankforge.git
cd rankforge
npm ci --include=dev
npm run build
npm start
```

Репозиторий публичный. Для скачивания исходников не нужен доступ к аккаунту автора.

После сообщения `Rankforge is ready` открой в браузере:

```text
http://127.0.0.1:4173
```

Оставь терминал с `npm start` работающим. Это локальный сервер игры. Браузер не открывается автоматически.

## Подключить наставника

1. В игре открой **Connection**.
2. Нажми **Connect ChatGPT**, затем **Continue with ChatGPT**.
3. Войди в свой аккаунт с подпиской, поддерживающей доступ к Codex, и вернись в игру.
4. Выбери доступную твоему аккаунту модель. Варианты в списке не гарантируют доступность каждой модели на любом тарифе.

Автор не передаёт свой аккаунт или квоту. Используется твоя подписка; отдельный API key не требуется. На macOS credentials хранятся в Keychain, на Linux - в Secret Service. Они не входят в репозиторий.

Карту и технические задания можно попробовать без подключения наставника. Для свободного общения и языковой обратной связи нужен аккаунт. Если отправил сообщение до подключения и игра приостановилась, подключи аккаунт и нажми **Resume saved answer**. При исчерпании квоты работает тот же механизм сохранения и продолжения; платного API-fallback нет.

## Как проходить задания

Выбери место на карте или **View quest** в режиме **Cards**. Карта и карточки переключаются на самом обзоре; условия задания, меню и профиль расположены ниже него. Просмотр задания не запускает редактор. Нажми **Accept mission & open VS Code**, чтобы подготовить отдельную учебную папку и открыть её в выделенном окне, либо **Prepare workspace only**, чтобы работать в своём редакторе. При первом открытии VS Code может попросить доверять этому локальному workspace.

В папке задания:

- `MISSION.md` описывает цель и условия проверки.
- `LEARN.md` объясняет нужные понятия и команды.
- Исходники - твоя рабочая область. Первоначально они специально содержат ошибку или незавершённое решение.

Читай задание, исследуй поведение, меняй код, сохраняй и нажимай **Verify lab** в игре. При успехе восстанавливается сектор базы и появляется награда. Повторная проверка не выдаёт ту же награду снова. Старые папки заданий сохраняются при переключении.

После обновления игры текущие требования видны в **How to complete this quest** и **Field manual · current contract**. Старые MISSION.md/LEARN.md сохраняются вместе с твоими заметками. Исходный безусловный503 в Signal — намеренный дефект, а не требование придумать отказ внешней зависимости.

Генеративные автоподстановки больших блоков кода в учебном окне отключены. Обычные подсказки имён, методов и параметров остаются. Это настройки учебного workspace, а не всех твоих рабочих проектов.

## Важное про сохранение и терминалы

VS Code не обязан сохранять каждую правку автоматически. Нажимай `Cmd+S` на Mac или `Ctrl+S` на Linux перед запуском и проверкой. Python и наставник читают сохранённый файл; то, что видно в несохранённом редакторском буфере, может отличаться.

В первом задании есть три разные роли:

1. Терминал с `npm start` обслуживает игру на порту4173.
2. Терминал задания с `python3 service.py` обслуживает учебный HTTP-сервер на порту45101.
3. Другой терминал с `curl` отправляет запрос этому серверу. Его можно открыть через **Terminal → New Terminal** в VS Code.

Отладочный `print` внутри `do_GET` появляется во втором терминале, когда приходит GET-запрос. Сам запуск сервера не вызывает `do_GET`. После изменения кода сохрани файл, останови именно учебный сервер через Ctrl+C и запусти его заново. Эта простая заготовка не делает hot reload.

Кнопка **Verify lab** в HTTP-задании запускает собственную короткую проверку на временном порту. Её результат не означает, что уже запущенный тобой процесс перечитал свежий файл.

## Как пользоваться чатом

Открой **Operator chat** в меню или **Open conversation** в панели задания. Это отдельное широкое рабочее пространство: история прокручивается внутри, поле ввода остаётся на экране.

- **Ask for guidance** - вопросы и помощь по заданию.
- **Mission debrief** - объяснение того, что ты сделал, с языковой обратной связью.
- **Oldest** и **Latest** переходят к началу или концу. Новые ответы не уводят вниз, если ты читаешь старые сообщения.
- Enter создаёт новую строку; `Ctrl+Enter` или `Cmd+Enter` отправляет сообщение.
- Markdown поддерживает выделение, списки, таблицы и кодовые блоки. У блока кода есть **Copy code**, копирующая сам код, без разметки.
- Выбранный режим, черновики и открытый чат восстанавливаются после обновления страницы.

Наставник получает текстовые файлы папки задания, включая добавленные тобой модули, с путями и временем сохранения. Размер снимка ограничен; пропуски и обрезанные файлы отмечаются. Несохранённые буферы и живой терминал он не видит. Если обсуждаешь ошибку, сохрани код и приложи относящийся к ней вывод терминала.

Наставник может ошибаться. Проверка технического результата опирается на реальные проверки задания, а не на его похвалу. Языковая обратная связь - учебная, не сертификат уровня.

## Обновление и данные

Останови сервер игры через Ctrl+C в его терминале. Из папки проекта выполни:

```sh
git pull --ff-only
npm ci --include=dev
npm run build
npm start
```

Обнови вкладку браузера. Сохранения и учебные папки находятся отдельно от исходников, по умолчанию в `~/.local/share/rankforge`. Обновление проекта их не удаляет. Для другого каталога можно задать `RANKFORGE_HOME`, для другого порта - `RANKFORGE_PORT`.

Если менял исходники самой игры, сначала сохрани свои изменения в Git. Рабочие файлы заданий расположены отдельно и не мешают обычному обновлению игры.

## Если что-то не запускается

- **`code` не найден:** установи команду через Command Palette и открой новый терминал.
- **Игра уже запущена:** используй существующую вкладку/адрес или сначала останови старый процесс. Два сервера не используют одну папку сохранений одновременно.
- **Нет наставника:** проверь подключение и доступность выбранной модели для своей подписки.
- **Правки не видны в задании:** проверь путь файла, сохрани его и перезапусти учебный процесс. Сравни время сохранения с тем, что сообщает наставник.
- **Порт nginx45103 занят:** в папке задания запусти `GATEWAY_PORT=45113 docker compose up -d` и используй новый порт. Проверяющий обнаружит его автоматически.
- **После обновления старая страница:** выполни `npm run build` и обнови вкладку. После изменений сервера нужен его перезапуск.
